# TICKET-UP 4주차: 제품 기획서 (초안 v0.1)

> 3주차 결정 사항을 반영한 기획서 초안입니다. 제품명, 테마, 수치는 가칭이며 팀 토론으로 확정합니다.

## 1. 확정된 결정 사항
| 항목 | 결정 |
|---|---|
| 핵심 메커닉 | **조준(Aim)** 중심. 타이밍과 반응 속도 게임은 제외 (미국 유저가 타이밍 게임에 약함) |
| 컨셉 | DUEL 기본안: 2대가 나란히 놓이면 1:1 대전, 1대면 AI/고스트 상대 |
| 네트워크 | **선택(Option)** 모듈. 없어도 완전한 단독 판매 가능 |
| 티켓 지급 | 사용자의 **카드에 적립** (직접 배출 없음). 한도 없음, 최대 보너스(Big Bonus) 약 5,000장 |
| 개발 범위 | 전체 자체 개발: 디자인, 기구 설계, 전장, 프로그램 |
| 타깃 | 10세 이상 남성 |
| 시장 | 미국, 독립 FEC 중심 + 유통사 채널 |

## 2. 제품 개요 (가칭)
- **가칭**: AIM DUEL
- **한 줄**: 정확하게 맞히는 쪽이 이기는 1:1 조준 대결 리뎀션 게임. 나란히 놓으면 대전, 혼자면 AI/고스트와 대결.
- **핵심 가치**
  - 룰이 5초 안에 이해된다 (맞히면 점수, 정확할수록 높다).
  - 실력이 늘면 티켓이 늘어난다 (연습할 이유가 생긴다).
  - 친구와 2대로 붙으면 더 재밌다 (2대 구매 동기).

## 3. 테마 제안 (자유 선택안)
라이선스 비용 없이 자체 IP로 가는 것을 전제로 3개를 제안해요.

| 안 | 테마 | 장점 | 주의점 |
|---|---|---|---|
| **1 (추천)** | **사이버 아레나: 드론/로봇 사냥 대결** | 사람을 겨냥하지 않아 FEC 분위기에 안전하고, 10세 이상 남성에 맞는 SF 느낌. 시각 효과가 좋음 | 개성 있는 캐릭터와 세계관 필요 |
| 2 | 우주 방어전 (외계 생체 병기 격추) | 보스, 웨이브 연출이 쉬움 | 흔한 소재라 차별화가 약함 |
| 3 | 스포츠 사격 (클레이 사격, 표적 챌린지) | 규칙이 직관적이고 가족 고객에게 거부감 없음 | 10세 이상 남성에게는 연출이 약할 수 있음 |

**추천 이유(안 1)**: 사람을 향한 폭력 연출을 피해 매장 정책에 맞고, 자체 IP로 라이선스 비용이 없으며, 후속 시리즈와 시즌 이벤트로 확장하기 쉬워요.

## 4. 게임 설계 (조준 중심)
### 4.1 기본 규칙
- **라운드**: 60~90초, 3판 2선승 또는 1판 합산 (택1은 플레이 테스트로 결정)
- **타깃**: 이동하는 드론, 고정 표적, 방어막 코어 등. 크기와 속도가 다양
- **점수**: 명중 위치(중심일수록 높음), 연속 명중 배수, 효율(명중률)
- **타이밍 의존 요소 배제**: "정해진 순간에 맞춰야만 점수"가 되는 구조를 피한다. 표적은 일정 시간 머물며 정확히 조준할수록 이득이다.

### 4.2 대전 모드 (2대 연결)
- **공유 아레나**: 양쪽이 같은 표적을 두고 경쟁. 먼저 정확히 맞힌 쪽이 점수를 가져간다.
- **탈취 효과**: 연속 명중이 쌓이면 상대 점수 일부를 가져오는 특수 샷.
- **역전 장치**: 점수 차가 커지면 후반 보너스 표적으로 역전 가능성 부여 (한쪽만 일방적이면 재미가 떨어짐).
- **자동 감지**: 2대를 나란히 놓고 연결하면 대전 모드가 자동 활성화.

### 4.3 단독 모드 (1대)
- **AI 라이벌**: 플레이어 실력에 맞춰 난이도가 변하는 상대.
- **고스트**: 상위 기록자의 플레이를 재현 (네트워크 연결 시 다른 매장 기록 포함).
- 이 모드의 품질이 1대 판매의 성패를 좌우한다.

### 4.4 조준 입력 방식 (프로토타입 비교 대상)
| 방식 | 장점 | 단점 |
|---|---|---|
| 거치형 건 + 자이로/IMU | 직관적, 캘리브레이션 불필요하게 설계 가능 | 장시간 사용 시 오차 누적 대응 필요 |
| 광학 트래킹 건 | 정확함 | 조명, 유지보수에 민감 |
| 듀얼 스틱/트랙볼 조준 | 내구성 우수, 정밀 | 건 방식보다 몰입감이 약함 |

→ **3가지를 프로토타입으로 비교**한 뒤 결정. 내구성과 유지보수 편의(독립 FEC 기준)를 우선한다.

## 5. 티켓과 보상 설계 (카드 적립)
| 항목 | 내용 |
|---|---|
| 지급 방식 | 카드 시스템에 전자 티켓으로 적립, 물리 티켓 배출 장치 없음 |
| 기본 보상 | 점수 구간에 따라 단계별 지급 |
| 승리 보너스 | 대전에서 이기면 추가 지급 |
| Big Bonus | 최대 약 5,000장. **실력 조건(예: 퍼펙트 라운드, 연속 명중 기록)으로 달성**하도록 설계 |
| 한도 | 별도 한도 없음. 다만 운영자가 지급 테이블을 조정할 수 있게 설정 기능 제공 |

**장점**: 티켓 디스펜서가 없어 고장 요소와 부품, 유지보수 부담이 줄어요. 티켓 보충도 필요 없어요.

**확인이 필요한 사항**
1. **법규 검토**: 2주차 조사에서 일부 주(예: 플로리다)가 리뎀션 상품 가치에 한도를 두는 것으로 확인됐어요. "한도 없음"과 5,000장 Big Bonus가 주별 규정에 맞는지 법률 검토가 필요해요. 운영자가 지급 테이블을 조정할 수 있는 기능은 이 이유로도 유지하길 권해요.
2. **Big Bonus의 공정성**: 확률이 아니라 실력 달성 조건으로 설계하는 것이 스킬 게임 분류에 유리해요.
3. **수익 구조**: 플레이 1회 가격 대비 평균 지급 티켓(회수율)과 티켓당 상품 원가를 정해야 운영자 수익이 나와요.
4. **카드 연동**: 적립 연동 규격은 Intercard, Embed, Sacoa 등 각 벤더에 요청해야 해요.

## 7. 소프트웨어 구성 (초안)
- **게임 클라이언트**: 조준 판정, 대전 동기화, AI/고스트
- **운영 메뉴**: 가격, 지급 테이블, 난이도, 통계, 카드 시스템 설정
- **카드 연동 레이어**: 벤더별 어댑터 구조
- **선택 모듈(네트워크)**: 매장 간 랭킹, 시즌 이벤트, 원격 진단, 콘텐츠 업데이트
- **게임 엔진 선택**: 후보 비교 후 결정 (프로토타입 속도와 임베디드 성능 기준)

## 8. 인증과 규제 체크리스트
- UL 22, CSA C22.2 #60335-1, #60335-2-82 (2주차에서 확인된 조합)
- FCC 요건 (미확인, 확인 필요)
- 주별 스킬 게임과 리뎀션 규정 (지급 한도, 상품 가치 등)
- 무선/네트워크 모듈 추가 시 추가 인증 여부

## 9. 판매와 유통 전략 (개요)
- 유통사 경유: Betson, Moss, BMI 등
- 대형 체인: Dave & Buster's, Round1, Main Event 등은 시범 설치 대상
- 독립 FEC: 핵심 대상. 2대 세트 구성 패키지와 운영 수익 시뮬레이션 자료 제공
- 목표 5,000대: 약 2,500개 매장 기준. 대형 체인 약 800개만으로는 부족해서 독립 매장 비중이 커야 함
