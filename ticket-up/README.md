# Project TICKET-UP

티켓 리뎀션 게임기 도입 검토 프로젝트

## 목표
- 도입할 티켓 리뎀션 기종 후보를 조사하고, 비교 기준에 따라 최종 기종을 선정한다.

## 진행 단계
1. 요구사항 정리 (예산, 설치 공간, 목표 수익, 타깃 고객)
2. 후보 기종 조사 (제조사, 모델, 스펙, 가격)
3. 비교표 작성 및 점수화
4. 상위 후보 심층 검토 (레퍼런스, 현장 반응, A/S)
5. 최종 선정 및 보고
