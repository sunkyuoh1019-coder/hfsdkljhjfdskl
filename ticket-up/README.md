## 3주차 이후 확정 사항
- 게임 방식: 퀵플레이(1회 20~30초), 기구(전기기계) 중심, 비디오는 보조 역할 (기획서 v0.2)
- 핵심 메커닉: 조준 (타이밍, 반응 속도 제외)
- 네트워크: 선택 모듈
- 티켓: 카드 적립 방식, 한도 없음, Big Bonus 약 5,000장
- 개발 범위: 디자인, 기구, 전장, 프로그램 전체 자체 개발

## 목표
- 미국 시장에 티켓 리뎀션 게임기 **5,000대**를 공급하는 것을 목표로, 후보 기종을 조사하고 제품 기획 아이디어를 완성한다.

## 확정된 요구사항
| 항목 | 내용 |
|---|---|
| 예산 | 제한 없음 (고려하지 않음) |
| 목표 규모 | 미국 시장 5,000대 |
| 주요 채널 | 미국 FEC(Family Entertainment Center) 매장 |
| 채널 전략 | 독립 FEC 진출 필수 (대형 체인 약 800개만으로는 목표 부족), 유통사(Betson, Moss, BMI) 경유 |
| 매장당 운영 대수 | 2대 운영 매장이 다수 되는 것을 목표 (5,000대 ÷ 2대 ≈ 약 2,500개 매장) |
| 타깃 고객 | 10세 이상 남자 (주 타깃) |
| 일정 | 도입 일정은 미정, 제품 기획 아이디어는 약 1개월 안에 완성 |

## 이 요구사항이 의미하는 것
- **2대 단위 운영이 핵심**: 매장당 1대로는 5,000대 달성에 매장이 너무 많이 필요하다. 한 매장에서 2대를 나란히 놓고 운영하고 싶게 만드는 구성(대전, 협력, 세트 연출, 변주 가능한 콘텐츠)이 필요하다.
- **10세 이상 남자 타깃**: 어린이용 단순 티켓 게임보다 숙련도, 경쟁, 기록 도전, 스킬 기반 요소가 중요하다.
- **미국 FEC 환경**: 기존 리뎀션 존 배치, 티켓 배출 방식, 카드 결제(카드 리더) 연동, 안전/인증 요건을 확인해야 한다.

## 독립 FEC 진출 시 설계 고려사항
- **공간**: 매장이 작아서 소형 설치 면적, 2대 나란히 배치 시 좁은 공간에서도 운영 가능해야 한다.
- **운영 편의**: 직원 수가 적어 고장 대응, 티켓 보충, 정산이 쉬워야 한다. 원격 진단이나 간단한 유지보수가 강점이 된다.
- **A/S와 부품**: 독립 매장은 자체 기술 인력이 부족하므로 유통사 통한 부품 수급과 빠른 지원이 구매 결정 요소가 된다.
- **결제 호환**: 독립 FEC는 Intercard, Embed, Sacoa 등 다양한 카드 시스템을 쓰므로 다중 리더 호환이 필수다.
- **가격 민감도**: 대형 체인보다 초기 투자와 회수 기간에 민감하므로 수익 구조(플레이당 단가, 회수 기간)를 명확히 제시해야 한다.
