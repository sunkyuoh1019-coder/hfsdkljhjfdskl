# Project TICKET-UP

티켓 리뎀션 게임기 도입 검토 및 제품 기획 프로젝트

## 목표
- 미국 시장에 티켓 리뎀션 게임기 **5,000대**를 공급하는 것을 목표로, 후보 기종을 조사하고 제품 기획 아이디어를 완성한다.

## 확정된 요구사항
| 항목 | 내용 |
|---|---|
| 예산 | 제한 없음 (고려하지 않음) |
| 목표 규모 | 미국 시장 5,000대 |
| 주요 채널 | 미국 FEC(Family Entertainment Center) 매장 |
| 매장당 운영 대수 | 2대 운영 매장이 다수 되는 것을 목표 (5,000대 ÷ 2대 ≈ 약 2,500개 매장) |
| 타깃 고객 | 10세 이상 남자 (주 타깃) |
| 일정 | 도입 일정은 미정, 제품 기획 아이디어는 약 1개월 안에 완성 |

## 이 요구사항이 의미하는 것
- **2대 단위 운영이 핵심**: 매장당 1대로는 5,000대 달성에 매장이 너무 많이 필요하다. 한 매장에서 2대를 나란히 놓고 운영하고 싶게 만드는 구성(대전, 협력, 세트 연출, 변주 가능한 콘텐츠)이 필요하다.
- **10세 이상 남자 타깃**: 어린이용 단순 티켓 게임보다 숙련도, 경쟁, 기록 도전, 스킬 기반 요소가 중요하다.
- **미국 FEC 환경**: 기존 리뎀션 존 배치, 티켓 배출 방식, 카드 결제(카드 리더) 연동, 안전/인증 요건을 확인해야 한다.

## 1개월 기획 일정(안)
| 주차 | 작업 | 산출물 |
|---|---|---|
| 1주 | 미국 FEC 시장 조사 (매장 수, 운영사, 리뎀션 존 구성, 인기 기종) | 시장 개요 정리 |
| 2주 | 경쟁/참고 기종 조사 및 비교표 작성, 10세 이상 남성 선호 요소 분석 | 기종 비교표 |
| 3주 | 제품 컨셉 아이디어 도출 (2대 운영 구조 포함), 후보안 3개 이내로 압축 | 컨셉안 |
| 4주 | 최종 컨셉 선정, 기획서 작성 (게임 방식, 하드웨어 구성, 수익 모델, 인증 이슈) | 제품 기획서 |
